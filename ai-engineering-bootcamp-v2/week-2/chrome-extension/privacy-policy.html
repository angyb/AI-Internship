Ask Z-Bot — Privacy Policy

Effective date: 2026-08-27 · Extension version: 1.1.1

Ask Z-Bot is a Chrome extension that answers Zearn support questions by calling a backend Zearn Support Agent API (POST /agent). This policy explains what data is collected and how it is used.

What we collect

  • Questions you submit — sent to the configured Agent API so the agent can retrieve Zearn documentation and generate an answer. Questions are not stored by the extension itself.
  • Settings you save — Agent API URL, optional shared API key, and telemetry opt-in preference, stored in chrome.storage.sync on your browser profile.
  • Anonymous install ID — a random UUID in chrome.storage.local, sent as X-Install-Id for API rate limiting and to key optional durable preferences on the server. It does not identify you personally.
  • Optional profile preferences — if you use the Profile tab and click Save, your chosen role and grade bands are stored on the Agent API server, keyed by your install ID, so answers can be tailored across browser sessions. You can remove them anytime with Forget preference.
  • Optional error reports — only if you enable “Send anonymous error reports.” Reports include a short error message, install ID, and extension version. They never include your question text.

What we do not collect

  • Browsing history outside zearn.org pages where the overlay runs
  • Passwords, cookies, or Zearn account credentials
  • OpenAI / Google API keys (those stay on the server)

Data retention

Extension storage persists until you clear it or uninstall. Server-side logging and telemetry retention depend on the API operator’s configuration; telemetry is disabled unless the server sets TELEMETRY_ENABLED=true and you opt in.

Contact

This extension is part of an AI Internship / bootcamp project. For questions about this policy, open an issue on the project repository that ships Ask Z-Bot.
