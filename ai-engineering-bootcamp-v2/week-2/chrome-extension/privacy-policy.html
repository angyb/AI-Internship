Ask Z-Bot — Privacy Policy

Effective date: 2026-08-28 · Extension version: 1.1.3

Ask Z-Bot is a Chrome extension that answers Zearn support questions by calling a backend Zearn Support Agent API (POST /agent). This policy explains what data is collected and how it is used.

What we collect

  • Questions you submit — sent to the configured Agent API so the agent can retrieve Zearn documentation and generate an answer. The extension does not keep a local copy of your questions after the overlay is closed, but the API does persist questions, answers, and Think/Act/Observe (TAO) steps in Postgres when chat History is enabled, keyed by an anonymous install ID.
  • Settings you save — Agent API URL, optional shared API key, and telemetry opt-in preference, stored in chrome.storage.sync on your browser profile.
  • Anonymous install ID — a random UUID in chrome.storage.local, sent as X-Install-Id so the API can key History and Profile preferences. It does not identify you personally. Knowing the UUID is enough to read that install’s stored chats, so treat it like a capability token (the extension does not display it).
  • Optional profile preferences — if you use the Profile tab and click Save, your chosen role and grade bands are stored on the Agent API server, keyed by your install ID, so answers can be tailored across browser sessions. You can remove them anytime with Forget preference.
  • Optional error reports — only if you enable “Send anonymous error reports.” Reports include a short error message, install ID, and extension version. They never include your question text.

What we do not collect

  • Browsing history outside zearn.org pages where the overlay runs
  • Passwords, cookies, or Zearn account credentials
  • OpenAI / Google API keys (those stay on the server)

Your controls

  • History tab — delete a saved session to remove that transcript (questions, answers, and TAO steps) from the API database.
  • Profile tab — Forget preference removes stored role and grade bands.
  • Uninstalling the extension clears local Chrome storage. Server-side History remains until you delete sessions or the API operator drops the database.

Data retention

Extension storage persists until you clear it or uninstall. Server-side transcripts and profile preferences persist until you delete them (History delete-session / Forget preference) or the API operator drops the database. Telemetry is disabled unless the server sets TELEMETRY_ENABLED=true and you opt in; those reports never include question text.

Contact

This extension is part of an AI Internship / bootcamp project. For questions about this policy, open an issue on the project repository that ships Ask Z-Bot.
