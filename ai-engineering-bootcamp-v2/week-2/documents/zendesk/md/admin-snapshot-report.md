# Admin Snapshot Report

The Admin Snapshot Report provides a summary view of implementation progress, helping administrators more easily track usage goals and make data-driven decisions to celebrate successes and support improvements.

For users with a School Account, the Admin Snapshot Report shows a view of average teacher and student sign-ins, time students spent on Zearn, and the number of on or above grade-level lessons completed per student over the course of the selected time frame. Administrators can also view the school year total for on or above grade-level lessons per student.

By clicking on a metric, leaders can explore trends, view school-level highlights for highest and lowest performance, and access the full data set for each school.

This report can help identify schools to celebrate and support for their sign-ins, weekly Independent Digital Lesson completion goal, and progress towards the end of year lesson completion goal.
